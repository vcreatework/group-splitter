Group Splitter

Add a student and they join the next open group of 3 straight away.

Demo mode: data is saved only in this browser. Add your Supabase keys in the page to share it.

Use the phone number you registered with the institute. Each number can join only once. Made a mistake? Tap Remove me on your name (it shows only on the phone you added yourself from), then add yourself again.

Admin

Enter the admin password to import from Excel.

Import from Excel

Pick an .xlsx file with a name column and a phone column. 9-digit numbers get +94 added. You'll see what will be added or skipped before anything is saved.

After the split: one member of each group, please create a WhatsApp group using your group's numbers (tap Copy all numbers). Then cross-check that none of your members is in another group by mistake: type each number in the search box below and make sure it shows only your group.
